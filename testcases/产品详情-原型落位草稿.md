# 产品详情-原型落位草稿

- 来源原型：`requirments/日历改造/产品详情.html`
- 说明：本稿已按产品详情页真实可见区域整理，后续正式用例应继续挂在这些区域下面，不再回退为“起价逻辑/库存逻辑”这类抽象分组。

页面/弹层：产品详情

## 原型区域 -> 文字规则 -> 用例节点

1. 页面区域：头部价格信息区
   - 原型位置：产品详情页头部价格区，包含起售价、单位、优惠标签、报名人数文案
   - 页面动作：查看
   - 文字规则：
     - 仅 `一级品类=亲子游/营地教育` 或 `二级品类=亲子活动`，且同时满足 `产品类型=预订产品`、`库存类型=人数` 时，套用本次起价改造
     - 亲子游/亲子活动优先取 `同时含1成人价+1儿童价` 的可见可售场次，展示 `起/成人`、`起/儿童`
     - 若成人价与儿童价相同，合并展示一个价格，单位为 `起/人`
     - 亲子游/亲子活动找不到 `1成人+1儿童` 时，降级展示成人最低价，单位为 `起/人`
     - 营地教育优先找含 `1儿童价` 的可见可售场次，展示儿童起价，单位为 `起/人`
     - 若目标价格都找不到，则兜底展示所有可见可售场次最低起价，不展示单位
     - 同价场次按团期开始日期更早者取值
     - 报名人数文案统一为 `XXX人已报名`
     - 报名人数超过 `1w` 时按 `1.4w+`、`1w+` 形式展示
     - 无横幅且同时展示成人+儿童价且价格位数较长时，报名人数按两行样式展示
   - 后续用例节点：
     - 查看产品详情-头部起价展示（亲子游/亲子活动/营地教育）
     - 查看产品详情-头部起价降级逻辑（目标价格缺失）
     - 查看产品详情-报名人数文案与样式

2. 页面区域：价格说明入口热区
   - 原型位置：头部价格横幅区或起价第一行区，特殊场景为原调价优惠金额入口
   - 页面动作：点击
   - 文字规则：
     - 有横幅时，整个横幅区为价格说明入口热区
     - 无横幅时，包含起价在内的第一行区域为价格说明入口热区
     - 无问号解释时，沿用原调价优惠金额入口打开价格说明弹窗
   - 后续用例节点：
     - 查看产品详情-价格说明入口热区（有横幅/无横幅/无问号）

3. 页面区域：价格说明弹层
   - 原型位置：点击头部价格说明入口后弹出
   - 页面动作：查看 / 点击底部按钮 / 关闭
   - 文字规则：
     - 展示 `常规售价`，取起价对应场次原价
     - 展示 `优惠项`，包含调价、拼单立减；调价文案包含规则、优惠金额、截止时间或优惠仅剩提示
     - 展示 `当前起价`，需与详情头部保持一致
     - 起价存在拼单返现时，展示 `拼成再返` 文案
     - 若起价为组合价，优惠金额与单位按组合人数口径展示，不误加 `/人`
     - 展示 `起价说明`：
       - 第一条高亮起价对应线路+团期日期
       - 第二条儿童说明仅在存在单独儿童价时展示
       - 第三条为固定说明文案
   - 后续用例节点：
     - 查看价格说明弹层-信息结构（组合价/非组合价）
     - 查看价格说明弹层-优惠项展示（调价/拼单立减/返现）

4. 页面区域：价格说明弹层底部按钮
   - 原型位置：价格说明弹层底部固定按钮区
   - 页面动作：点击
   - 文字规则：
     - 产品可售时按钮为 `计算我的出行价格`，点击后关闭当前弹层并打开日历弹窗
     - 产品预售时按钮为 `开售提醒我`，点击逻辑与详情底部开售提醒一致
     - 产品不可售时按钮为 `我知道了`，点击仅关闭弹层
   - 后续用例节点：
     - 查看价格说明弹层-底部按钮（可售/预售/不可售）

5. 页面区域：选择团期入口
   - 原型位置：头部价格区下方 `选择团期` 入口
   - 页面动作：点击
   - 文字规则：
     - 点击 `选择团期` 进入日历弹窗
     - 入口位置与文案保持一致，作为产品详情进入日历弹窗的主入口之一
   - 后续用例节点：
     - 查看产品详情-选择团期入口跳转

6. 页面区域：团期卡片
   - 原型位置：产品详情团期列表卡片区
   - 页面动作：查看 / 点击查看更多团期
   - 文字规则：
     - 可售且库存 `<10` 显示 `仅余XX人/间房/车`
     - 可售且库存 `>=10` 显示 `报名中`
     - 不可售可候补显示 `余位通知`
     - 不可售不可候补不展示库存占位字段，仅保留 `已满员`
     - 老版本兼容场景下，`可候补/余位紧张` 旧标签按兼容策略处理
   - 后续用例节点：
     - 查看产品详情-团期卡片状态文案（可售/候补/售罄）

7. 页面区域：月份Tab与查看更多团期
   - 原型位置：产品详情团期卡片区域上方月份Tab、下方 `查看更多团期` 按钮
   - 页面动作：查看 / 点击
   - 文字规则：
     - 月份Tab按 `最多6个有团期月份` 展示，不按当前日期顺推6个月
     - 按钮文案为 `查看更多团期`
     - 点击后打开 `全部出行日期弹窗`
   - 后续用例节点：
     - 查看产品详情-月份Tab展示规则
     - 查看产品详情-查看更多团期跳转

8. 页面区域：详情底部价格与按钮区
   - 原型位置：产品详情底部固定价格和操作按钮区
   - 页面动作：查看
   - 文字规则：
     - 底部按钮价格取值与头部最低价保持一致
     - 有拼单立减时，底部同时展示 `最低价 + 对应拼单优惠前原价`
     - 无拼单立减时，仅展示一个价格
   - 后续用例节点：
     - 查看产品详情-底部价格取值一致性

## 自检
- 每条起价规则是否已经挂到了 `头部价格信息区`、`价格说明弹层` 或 `详情底部价格与按钮区`，而不是单独写成抽象逻辑块。
- 每条点击规则是否已经挂到了 `价格说明入口热区`、`选择团期入口`、`查看更多团期` 这类真实操作区。
- 每个后续用例节点是否都能直接放进脑图，不需要再二次改名。
