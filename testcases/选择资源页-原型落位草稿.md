# 选择资源页-原型落位草稿

- 来源原型：`requirments/日历改造/选择资源页.html`
- 说明：本页规则量不大，但必须继续按真实页面区域挂载，避免把“资源页UI重构”这种需求章节名直接当模块名。

页面/弹层：选择资源页

## 原型区域 -> 文字规则 -> 用例节点

1. 页面区域：进度条
   - 原型位置：选择资源页顶部流程进度区
   - 页面动作：查看
   - 文字规则：
     - 页面新增进度条
     - 默认高亮 `选择服务`
   - 后续用例节点：
     - 查看选择资源页-进度条默认高亮

2. 页面区域：已选信息回显区
   - 原型位置：资源页头部或资源列表上方，展示从日历页带入的已选信息
   - 页面动作：查看
   - 文字规则：
     - 日历页已选信息正确回显到资源页
     - 回显内容包含日期、人数、套餐等已选信息
     - 信息展示无缺失、无错位、无串行
   - 后续用例节点：
     - 查看选择资源页-已选信息回显

3. 页面区域：资源卡片区
   - 原型位置：资源页主体资源列表
   - 页面动作：查看
   - 文字规则：
     - 不同资源类型展示不同 icon
     - 至少覆盖 `交通`、`住宿`、`门票`、`其他` 四类资源类型
     - icon 与资源类型映射正确
   - 后续用例节点：
     - 查看选择资源页-资源类型Icon

4. 页面区域：我要咨询入口
   - 原型位置：资源页底部或固定操作区 `我要咨询` 入口
   - 页面动作：点击
   - 文字规则：
     - 一级品类=亲子游或二级品类=多日营时，点击后走产品客服员工获客链接
     - 小程序形态下展示二维码弹窗
     - 其他品类优先进产品咨询群
     - 若产品未配置咨询群，则隐藏该入口，不出现死链按钮
   - 后续用例节点：
     - 查看选择资源页-我要咨询入口分流（亲子游/多日营）
     - 查看选择资源页-我要咨询入口分流（其他品类）
     - 查看选择资源页-未配置咨询群隐藏入口

## 自检
- 当前模块名是否都是页面上真实能看到的区域，而不是需求章节名。
- 咨询规则是否只挂在 `我要咨询入口` 下，没有混回 `页面UI` 总述里。
