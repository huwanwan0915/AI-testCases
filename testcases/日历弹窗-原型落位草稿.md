# 日历弹窗-原型落位草稿

- 来源原型：`requirments/日历改造/日历弹窗.html`
- 说明：本稿已把 `日历与人数弹窗`、`全部日期弹窗`、`附属弹窗` 放在同一页链路下梳理，后续正式 case 应继续按操作流挂载。

页面/弹层：日历弹窗

## 使用说明
- 先按原型图从上到下补充真实区域位置。
- 再把需求文档里的文字规则逐条挂到对应区域。
- 最后再补“后续用例节点”，不要跳过落位直接写 case。

## 原型区域 -> 文字规则 -> 用例节点

1. 页面区域：弹窗UI与套餐区
   - 原型位置：日历弹窗顶部标题区、关闭按钮、线路/套餐选择区
   - 页面动作：查看 / 关闭 / 切换线路或套餐
   - 文字规则：
     - 一级品类=亲子游、二级品类=多日营的产品，用户端不展示场次维度数据和选择
     - 多线路产品展示已选线路名称+天数及套餐选择，已选套餐高亮
     - 单线路产品展示固定标题+套餐选择，已选套餐高亮
     - 有团期无套餐时展示全部套餐；无团期有套餐时仅展示已选套餐
   - 后续用例节点：
     - 查看日历弹窗-默认态与套餐区展示（多线路/单线路）

2. 页面区域：月份Tab与团期卡片
   - 原型位置：日历弹窗月份Tab区、团期卡片列表区
   - 页面动作：查看 / 切换月份 / 选择团期
   - 文字规则：
     - 带日期参数进入时自动定位并选中对应月份与团期
     - 不带日期参数时默认定位第一个月份，不默认选中具体团期
     - 仅一个月份时不展示月份Tab
     - 同一开始-结束日期下多个场次时，默认取可售最新创建场次；开始时间相同结束不同按两个团期展示
     - 团期卡片状态文案按库存与售卖状态展示
   - 后续用例节点：
     - 查看日历弹窗-月份与团期默认选中逻辑
     - 查看日历弹窗-团期卡片状态文案

3. 页面区域：出行人数区
   - 原型位置：团期选中后的成人/儿童人数选择区
   - 页面动作：查看 / 选择人数 / 切换团期后观察携带
   - 文字规则：
     - 人数文案按规则展示，如 `1成人&1儿童`、`1成人&2儿童`
     - 一级品类=亲子游且存在单儿童规则时，按规则展示 `不占床` 标识
     - 切换团期默认携带已选人数
     - 若新团期年龄带不匹配，不携带并提示 `所选日期出行人年龄限定发生变化，请重新选择`
   - 后续用例节点：
     - 查看日历弹窗-出行人数与年龄标识
     - 查看日历弹窗-切换团期后人数携带

4. 页面区域：房间数/车辆数补差区
   - 原型位置：出行人数区下方房间数、车辆数、补差说明区域
   - 页面动作：查看 / 点击说明入口
   - 文字规则：
     - 仅在需要补差时展示房差/车差说明文案与补差金额
     - 点击房间数区域打开房差说明弹窗
     - 点击车辆说明区触发咨询专员获客路径
   - 后续用例节点：
     - 查看日历弹窗-房差/车差说明与交互

5. 页面区域：底部已选浮条与底部按钮区
   - 原型位置：日历弹窗底部固定价格、已选提醒、主按钮/双按钮区
   - 页面动作：查看 / 点击下一步 / 点击候补按钮 / 点击咨询按钮
   - 文字规则：
     - 未选人数时价格显示 `-`，副文案提示选择必要项，点击 `下一步` 触发对应 toast
     - 选完人数后按规则计算价格并展示金额明细入口；有优惠时展示优惠标识
     - 已选提醒展示 `团期开始日期+套餐名称`，超出一行省略
     - 选中不可售可候补场次时，底部展示 `添加专员 + 余位通知` 双按钮
     - 无咨询群配置时，不展示无效咨询入口
   - 后续用例节点：
     - 查看日历弹窗-底部栏与下一步按钮（可售）
     - 查看日历弹窗-可候补场次底部双按钮
     - 查看日历弹窗-优惠金额计算与展示

6. 页面区域：余位短信提醒弹窗
   - 原型位置：点击 `余位通知` 后打开的登记弹窗
   - 页面动作：查看 / 输入手机号 / 提交
   - 文字规则：
     - 展示已选线路套餐、日期区间、人数信息
     - 手机号非法时 toast 提示 `请填写合法的手机号`
     - 登记成功后关闭弹窗并回到日历弹窗，toast 提示 `登记成功，请关注短信提醒`
   - 后续用例节点：
     - 查看余位短信提醒弹窗-展示与提交

7. 页面区域：房差说明弹窗与金额明细弹窗
   - 原型位置：点击房差说明或金额明细入口后打开
   - 页面动作：查看 / 点击咨询专员 / 关闭
   - 文字规则：
     - 房差说明弹窗展示固定图片+文案
     - 点击 `咨询专员` 走获客链路
     - 金额明细弹窗展示基础商品与优惠明细，包括成人/儿童/房差/车差/拼单立减/早鸟立减/会员价等
   - 后续用例节点：
     - 查看房差说明弹窗
     - 查看金额明细弹窗

8. 页面区域：全部日期弹窗-头部月份区
   - 原型位置：点击 `查看全部日期` 后弹出的全部日期弹窗顶部
   - 页面动作：查看 / 切换月份 / 关闭
   - 文字规则：
     - 弹窗从底部弹出，不是直接出现
     - 顶部展示所有月份和对应起价
     - 点击月份Tab可快捷滚动到对应月份并切换高亮
     - 关闭后回到上层日历与人数弹窗
   - 后续用例节点：
     - 查看全部日期弹窗-样式、跳转与关闭回退

9. 页面区域：全部日期弹窗-日期列表区
   - 原型位置：全部日期弹窗主体日历日期网格区
   - 页面动作：查看 / 点击日期
   - 文字规则：
     - 节假日当天显示节假日名，其他节假日显示 `休`
     - `今天` 的优先级低于节假日规则
     - 无场次/未成团日期灰态不可选
     - 已满员/已关闭/已截止日期高亮 `已满员` 且不可选
     - 可售日期展示起价和状态文案，如 `仅余XX`、`报名中`、`有余位通知我`、`已成团`
     - 一级品类=亲子游、二级品类=多日营默认取 `可售且结束时间最早` 场次作为日期展示依据
     - 其他品类按补充规则取 `可售且成团且开始时间最早` 场次
   - 后续用例节点：
     - 查看全部日期弹窗-日期状态渲染与可选性
     - 查看全部日期弹窗-同日多场次取值规则

10. 页面区域：全部日期弹窗-底部咨询入口
   - 原型位置：全部日期弹窗底部固定咨询入口
   - 页面动作：点击
   - 文字规则：
     - 固定添加客服入口，走获客链接
     - 配置群聊时展示 `进群咨询`
     - 候补场景下，有咨询群时展示 `进群咨询 + 余位短信通知`；无咨询群时仅保留短信通知按钮
   - 后续用例节点：
     - 查看全部日期弹窗-咨询入口分支

11. 页面区域：出行时间模块（多场次品类）
   - 原型位置：除亲子游一级品类/多日营二级品类外的其他品类日历弹窗中，日期下方场次横滑区
   - 页面动作：查看 / 切换日期 / 选择场次
   - 文字规则：
     - 非亲子游/多日营品类展示场次维度和选择
     - 单场次默认选中，多场次不默认选中，支持横向滑动查看
     - 切换日期后若存在同起止且可售场次则自动携带；不可售则不携带并提示 `指定时间已无余位，请重新选择`
     - 不可售不可候补场次不可选，点击提示 `当前场次已无余位，报名其他场次吧`
   - 后续用例节点：
     - 查看日历弹窗-多场次选择与场次携带

12. 页面区域：资源加价购浮条与候补咨询分支
   - 原型位置：多场次品类日历弹窗底部已选提醒上方浮条区
   - 页面动作：查看 / 点击咨询入口
   - 文字规则：
     - 选中可售场次且配置绑定资源加价购时，展示资源浮条
     - 绑定资源全部不可售时，展示资源不可售提示文案
     - 候补场景有咨询群时展示 `进群咨询`；无咨询群时隐藏对应入口
   - 后续用例节点：
     - 查看日历弹窗-底部资源浮条与咨询分支

13. 页面区域：卡预约点数展示区
   - 原型位置：卡预约场景下的按钮、价格区、全部日期日期文案区
   - 页面动作：查看 / 点击
   - 文字规则：
     - 无可约套餐时按钮文案 `暂无可约套餐`，不可点击
     - 有可约套餐时按钮文案 `立即预约`
     - 日历页按钮与价格区展示 `消耗N点/消耗N点起`
     - 全部日期弹窗日期上展示 `起约N点`
   - 后续用例节点：
     - 查看卡预约-按钮与点数文案
